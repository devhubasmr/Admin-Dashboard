# Admin Dashboard

A responsive admin dashboard with light and dark mode.

## Getting Started

```bash
git clone https://github.com/devhubasmr/Admin-Dashboard.git
cd Admin-Dashboard
```

Then open `index.html` in your browser.

- HTML
- CSS
- JavaScript
